# Client manual accessibility test checklist

- [ ] Page has a meaningful document title and `lang` attribute.
- [ ] Keyboard users can reach all interactive controls in a logical order.
- [ ] Focus is visible and not obscured.
- [ ] Skip link moves focus/navigation to main content.
- [ ] Links and buttons have meaningful accessible names.
- [ ] Status messages are announced (test with a screen reader where possible).
- [ ] Text and controls meet WCAG contrast requirements.
- [ ] Layout works at 200% zoom and on a narrow viewport.
- [ ] Images have appropriate alternative text (or empty alt for decorative images).
- [ ] Form fields have persistent labels and clear error messages, if forms are added.
